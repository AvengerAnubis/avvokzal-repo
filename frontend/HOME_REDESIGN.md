## Основные компоненты PrimeReact для использования
- `Card` — для секций и карточек
- `Button` — кнопки навигации
- `Image` — для изображений (если нужны)
- `Carousel` — для отзывов (опционально)
- `Divider` — разделители секций
- `Ripple` — эффекты

# ВВЕДЕНИЕ

Проблема. В быстро меняющемся мире пассажирских перевозок, где появляются новые маршруты, меняются расписания и растёт спрос на цифровые сервисы, создание актуальной информационной системы для автовокзала – сложная задача. Обновление каталога маршрутов, синхронизация расписаний рейсов, и интеграция современных онлайн-сервисов (бронирование билетов, электронные билеты с QR-кодами, отслеживание задержек в реальном времени) требуют постоянных усилий. Отставание от трендов приводит к потере пассажиров и снижению конкурентоспособности автовокзала.

Актуальность. В связи с этим, крайне важно создать эффективную информационную систему для автовокзала. Она должна предоставлять актуальную информацию о маршрутах и расписаниях, обеспечивать удобное онлайн-бронирование и оплату билетов, а также включать мобильное приложение для пассажиров, панели управления для водителей и операторов. Всё это необходимо для привлечения и удержания клиентов в условиях быстро меняющегося рынка пассажирских перевозок.

Для разработки будет использован современный стек технологий: NextJS для фронтенда, NestJS для бэкенда, PostgreSQL для базы данных и .NET MAUI для мобильного приложения. Этот выбор обусловлен популярностью каждой технологии, строгими архитектурами, безопасностью и высокой производительностью, что ускоряет процесс разработки и обеспечивает долгосрочную поддержку проекта. Дизайн системы будет ориентирован на удобство пользователя, обеспечивая легкую навигацию и быстрый поиск нужных маршрутов и рейсов.

Объектом курсового проекта является проектирование и разработка информационной системы автовокзала «АВ-Вокзал».
Предметом квалификационной работы является создание информационной системы автовокзала с использованием фреймворков NextJS, NestJS и .NET MAUI.

Цель работы: разработка и создание информационной системы автовокзала «АВ-Вокзал» на основе современных веб- и мобильных технологий.

Для достижения цели проекта необходимо решить следующие задачи:
- Проанализировать современные фреймворки и их возможности для веб- и мобильной разработки;
- Проанализировать существующие системы бронирования автобусных билетов;
- Разработать структуру, дизайн и макет веб-приложения и мобильного приложения;
- Выполнить создание веб-приложения с использованием NextJS и NestJS;
- Выполнить создание мобильного приложения с использованием .NET MAUI;
- Спроектировать и реализовать базу данных PostgreSQL с использованием PrismaORM;
- Реализовать систему ролевого доступа (USER, ADMIN, DRIVER, OPERATOR);
- Реализовать функционал бронирования и оплаты билетов;
- Реализовать систему электронных билетов с QR-кодами;
- Реализовать систему чата между водителями и операторами;
- Реализовать систему отслеживания задержек рейсов.

Теоретическая значимость. Разработать требования к структуре информационной системы автовокзала, раскрыть возможности применения фреймворков NextJS, NestJS и .NET MAUI на примере создания системы бронирования билетов и управления автовокзалом.

Практическая значимость. Разработана полнофункциональная информационная система автовокзала, включающая веб-приложение с системой бронирования и оплаты билетов, электронными билетами с QR-кодами, мобильное приложение для пассажиров, панели управления для администраторов, водителей и операторов, систему чата и отслеживания задержек.

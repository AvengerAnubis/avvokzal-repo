## Создание Базы Данных

Для обеспечения корректной работы информационной системы «АВ-Вокзал» необходимо организовать надёжное хранение и обработку информации о пользователях, маршрутах, рейсах, бронированиях, билетах и платежах. С этой целью в рамках проекта разработана структурированная реляционная база данных на основе PostgreSQL.

Используемая модель данных обеспечивает целостность информации, удобство администрирования и возможность дальнейшего расширения функционала системы. Структура базы данных включает таблицы пользователей, маршрутов, рейсов, бронирований, билетов, платежей, избранных маршрутов, задержек рейсов и сообщений чата.

Таблица пользователей (users) предназначена для хранения учётных данных всех участников системы с ролевым разделением (USER, ADMIN, DRIVER, OPERATOR). Таблица маршрутов (routes) хранит информацию о автобусных маршрутах: название, описание, пункт отправления, пункт назначения, расстояние, продолжительность и цену. Таблица рейсов (trips) содержит данные о конкретных поездках по маршрутам с указанием времени отправления, прибытия, статуса, номера автобуса и назначенных водителя и оператора.

Таблица бронирований (bookings) хранит информацию о бронированиях билетов пользователями, включая количество мест, общую стоимость и статус. Таблица билетов (tickets) содержит данные об электронных билетах с уникальными QR-кодами. Таблица платежей (payments) фиксирует информацию об оплатах бронирований.

Таблица избранных маршрутов (favorites) позволяет пользователям сохранять любимые маршруты. Таблица задержек (delays) фиксирует задержки рейсов с указанием причины и продолжительности. Таблица сообщений чата (chat_messages) обеспечивает коммуникацию между водителями и операторами.

Связи между таблицами реализованы с использованием ключевых полей, что позволяет поддерживать согласованность данных и корректную работу системы. Подробная структура базы данных представлена в приложении А.

В системе реализовано разграничение прав доступа на основе ролей. Пользователи (USER) могут бронировать билеты, оплачивать брони, просматривать свои билеты и управлять избранными маршрутами. Администраторы (ADMIN) имеют полный доступ к управлению маршрутами, рейсами и учётными записями. Водители (DRIVER) могут просматривать назначенные рейсы и общаться с операторами. Операторы (OPERATOR) могут просматривать задержки, маршруты и корректировать время рейсов. Аутентификация пользователей обеспечивает защищённый доступ к соответствующим разделам системы.

Разработанная база данных обеспечивает централизованное хранение информации, защиту конфиденциальных данных и возможность масштабирования системы за счёт добавления новых сущностей и модулей.

## Разработка информационной системы «АВ-Вокзал»

После инициализации проекта на NextJS и NestJS мы установили необходимые зависимости для дальнейшей разработки. Вот основные инструменты и библиотеки, которые мы использовали:

PostgreSQL – система управления базами данных для хранения информации о пользователях, маршрутах, рейсах, бронированиях и билетах.
NestJS Framework – основа бэкенда, обеспечивающая модульную архитектуру и встроенные компоненты.
PrismaORM – ORM для типизированной работы с базой данных.
NextJS – основа фронтенда, обеспечивающая серверный рендеринг и маршрутизацию.
PrimeReact – библиотека компонентов для создания пользовательского интерфейса.
TailwindCSS – фреймворк для стилизации компонентов.
Axios – библиотека для HTTP-запросов к бэкенд-API.
.NET MAUI – фреймворк для создания кроссплатформенного мобильного приложения.

После установки зависимостей мы приступили к разработке. Первым шагом стала настройка подключения к базе данных PostgreSQL через конфигурационный файл .env и создание схемы Prisma для основных таблиц.

Была разработана основная структура веб-приложения с использованием NextJS App Router, включая главную страницу, страницы авторизации, выбора маршрутов, бронирования, оплаты, профиля пользователя и электронных билетов. Роутинг приложения был настроен через файловую систему NextJS, что обеспечивает четкую структуру URL и корректное отображение всех элементов интерфейса.

Основной шаблон layout.tsx содержит общие элементы сайта – заголовок, навигационное меню, футер, что обеспечивает единообразие интерфейса across всех страниц. Динамический контент подгружается через систему серверных и клиентских компонентов NextJS, что упрощает поддержку и дальнейшее развитие проекта.

## ВЫВОД ПО 2 ГЛАВЕ

Разработка информационной системы «АВ-Вокзал» была выполнена на современном стеке технологий с использованием NextJS для фронтенда, NestJS для бэкенда, PostgreSQL для базы данных и .NET MAUI для мобильного приложения. Начальным этапом стало проектирование структуры приложения, включающей основные разделы: главную страницу, авторизацию, каталог маршрутов, бронирование билетов, оплату, личный кабинет и электронные билеты.

Для работы с данными была создана структура базы данных PostgreSQL, обеспечивающая надежное хранение информации о пользователях, маршрутах, рейсах, бронированиях, билетах и платежах. Интерфейсная часть реализована с использованием React-компонентов NextJS и библиотеки PrimeReact, что гарантирует адаптивное отображение на всех устройствах.

Серверная часть приложения была построена с использованием модульной архитектуры NestJS. Мы реализовали систему миграций через PrismaORM для управления структурой базы данных, что позволяет легко вносить изменения и поддерживать согласованность данных на разных этапах разработки. Были созданы сервисы для работы с основными сущностями приложения, разработаны контроллеры для обработки бизнес-логики и настроены маршруты для обеспечения корректной работы REST API.

Особое внимание было уделено системе аутентификации и авторизации. Мы реализовали многоуровневую систему доступа на основе ролей (USER, ADMIN, DRIVER, OPERATOR), которая предоставляет различные права каждому типу пользователей. Для защиты данных внедрены механизмы валидации входных параметров, защита от CSRF-атак и SQL-инъекций, а также хеширование паролей.

Пользовательский интерфейс был разработан с использованием React-компонентов и библиотеки PrimeReact. Мы создали адаптивный дизайн, который корректно отображается на устройствах с различными размерами экранов. Основной акцент был сделан на удобстве использования: реализована интуитивно понятная навигация, удобная система фильтрации маршрутов и упрощенный процесс бронирования билетов.

Функциональная часть системы включает несколько ключевых модулей. Система бронирования позволяет пассажирам выбирать маршруты, рейсы, указывать количество мест и данные пассажиров. Модуль оплаты обеспечивает обработку платежей и формирование электронных билетов с QR-кодами. Личный кабинет пользователя предоставляет доступ к истории бронирований, избранным маршрутам и электронным билетам. Панель администратора дает возможность управлять маршрутами, рейсами и учётными записями. Панели водителя и оператора обеспечивают оперативное управление рейсами и коммуникацию через встроенный чат.

Для повышения производительности были реализованы различные оптимизации. Мы настроили кэширование часто запрашиваемых данных, оптимизировали запросы к базе данных через PrismaORM, сжали статические ресурсы и настроили серверный рендеринг NextJS для быстрой загрузки страниц.

Результатом работы стала полнофункциональная информационная система, которая сочетает в себе современный дизайн, удобный интерфейс и надежную серверную часть. Система эффективно решает задачи автовокзала: привлекает новых пассажиров, упрощает процесс бронирования билетов и автоматизирует многие бизнес-процессы. Система демонстрирует стабильную работу даже при высокой нагрузке и предоставляет возможности для дальнейшего расширения функциональности.

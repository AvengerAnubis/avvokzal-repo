# Правила написания диплома

Данный файл содержит правила оформления и написания текста дипломной работы. AI-агент обязан следовать им при генерации любого контента.

---

## 1. Язык и стиль

### 1.1. Запрещённые местоимения
- НЕ использовать местоимения первого лица: **я, мы, мой, наш, мне, нам, меня, нас** и их производные.
- Текст пишется в безличной или пассивной форме.

### 1.2. Запрет на «был / была / были / было»
- НЕ использовать формы глагола «быть» в прошедшем времени: **был, была, были, было**.
- ДОПУСТИМО: «разработано», «создано», «реализовано», «представлено» — без связки «было».
- Примеры:
  - НЕЛЬЗЯ: «Было разработано приложение...»
  - МОЖНО: «Разработано приложение...»

### 1.3. Научный стиль
- Текст пишется в строгом научном/академическом стиле.
- НЕ допустимы: художественные обороты, метафоры, эмоциональные оценки, разговорные выражения.
- Допустимы: факты, формулировки, определения, описания технических решений.

---

## 2. Объём

### 2.1. Подглавы
- Каждая подглава (например, 1.1, 1.2, 2.3) — **минимум 3 страницы** текста.

---

## 3. Листинги кода

### 3.1. Обязательное обращение
- Каждый листинг кода **должен быть упомянут в тексте** до его размещения.
- Формат обращения: `«... показан в листинге X»`, где X — порядковый номер листинга.
- Пример: «Код авторизации пользователя показан в листинге 1.»

### 3.2. Нумерация
- Листинги нумеруются сквозной нумерацией по всей работе: листинг 1, листинг 2, ...

### 3.3. Формат листинга
- Каждый листинг обрамляется метками `[листинг_X]` и `[листинг_X_конец]`, где X — порядковый номер.
- Пример:
```
[листинг_1]
function Hello({smth}: {smth: Number}){
  return smth + 1;
}
[листинг_1_конец]
```

### 3.4. Требования к коду в листингах
- НЕ включать большие фрагменты (целые классы — только если они небольшие).
- Предпочтительны отдельные методы/функции, выполняющие конкретную задачу.
- Листинги НЕ должны содержать комментариев.
- Код берётся из реального проекта, комментарии удаляются, пустые строки сжимаются.

---

## 4. Рисунки

### 4.1. Обязательное обращение
- Каждый рисунок **должен быть упомянут в тексте** до его размещения.
- Формат обращения: `«... показано на рисунке X»`, где X — порядковый номер рисунка.
- Пример: «Страница регистрации пользователя показана на рисунке 1.»

### 4.2. Нумерация
- Рисунки нумеруются сквозной нумерацией по всей работе: рисунок 1, рисунок 2, ...

---

## 5. Расположение элементов

### 5.1. Запрет на два одинаковых элемента подряд
- НЕЛЬЗЯ размещать два листинга кода подряд — между ними **минимум 3 строки текста**.
- НЕЛЬЗЯ размещать два рисунка подряд — между ними **минимум 3 строки текста**.
- НЕЛЬЗЯ размещать листинг и рисунок подряд — между ними **минимум 3 строки текста**.
- Между любыми двумя вставными элементами (листинг, рисунок, таблица) должно быть **не менее 3 строк связного текста**.

---

## 6. Чек-лист для AI-агента

Перед выдачей результата проверить:

- [ ] Нет местоимений первого лица (я, мы, мой, наш...)
- [ ] Нет форм «был / была / были / было»
- [ ] Стиль — научный, без художественных элементов
- [ ] Каждая подглава содержит минимум 3 страницы текста
- [ ] Каждый листинг упомянут в тексте («листинг X»)
- [ ] Каждый рисунок упомянут в тексте («рисунок X»)
- [ ] Между любыми двумя вставными элементами — минимум 3 строки текста

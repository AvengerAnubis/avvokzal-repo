# ВВЕДЕНИЕ

Проблема. В быстро меняющемся мире автосервиса, где появляются новые модели автомобилей и технологии, создание актуального веб-сайта – сложная задача. Обновление каталога услуг, описание новых технологий (вроде ремонта электрокаров), и интеграция современных онлайн-сервисов (запись, отслеживание) требуют постоянных усилий. Отставание от трендов приводит к потере клиентов.
Актуальность.  В связи с этим, крайне важно создать эффективный веб-сайт для автосервиса. Он должен предоставлять актуальную информацию об услугах, технологиях и обеспечить удобную онлайн-запись, чтобы привлечь и удержать клиентов в условиях быстро меняющегося рынка.
Для разработки сайта будет использован современный фреймворк Laravel. Этот выбор обусловлен его популярностью, широким инструментарием, строгой архитектурой MVC и безопасностью, что ускоряет процесс разработки и обеспечивает долгосрочную поддержку проекта. Дизайн сайта будет ориентирован на удобство пользователя, обеспечивая легкую навигацию и быстрый поиск нужной информации. Использование встроенных в Laravel возможностей работы с базами данных позволит удобно и безопасно реализовать функциональность поиска, онлайн-записи и хранения данных.
Объектом курсового проекта является проектирование и разработка веб-сайта для автосервиса.
 Предметом квалификационной работы является создание веб-сайта для автосервиса с использованием фреймворка.
Цель работы: разработка и создание web-сайта для автосервиса на основе фреймворка Laravel.
Для достижения цели проекта необходимо решить следующие задачи:
Проанализировать современные фреймворки и их возможности для веб-разработки;
Проанализировать уже готовые сайты автосервисов;
Разработать структуру, дизайн и макет сайта;
Выполнить создание веб-сайта с использованием фреймворка и базы данных MySQL;
Теоретическая значимость. Разработать требования к структуре сайта, раскрыть возможности применения фреймворка на примере создания сайта автосервиса.
Практическая значимость. Разработан полнофункциональный web-сайт автосервиса на фреймворке, включающий систему онлайн-записи, управление услугами и базу данных.

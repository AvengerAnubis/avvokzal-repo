# Создание Базы Данных

Для обеспечения корректной работы веб-сайта автосервиса необходимо организовать надёжное хранение и обработку информации о клиентах, их обращениях и заявках на оказание услуг. С этой целью в рамках проекта разработана структурированная реляционная база данных.
Используемая модель данных обеспечивает целостность информации, удобство администрирования и возможность дальнейшего расширения функционала системы. Структура базы данных включает таблицы заявок, обращений клиентов и пользователей системы.
Таблица заявок предназначена для хранения информации о поступающих запросах на оказание услуг. Таблица обращений клиентов используется для фиксации сообщений и обратной связи. Таблица пользователей обеспечивает функционирование административного раздела системы и хранение учётных данных.
Связи между таблицами реализованы с использованием ключевых полей, что позволяет поддерживать согласованность данных и корректную работу системы. Подробная структура базы данных представлена в приложении А.
В системе реализовано разграничение прав доступа. Клиенты могут отправлять заявки через формы сайта без регистрации. Администратор имеет доступ к панели управления, где осуществляется просмотр и обработка поступающих обращений. Аутентификация пользователей обеспечивает защищённый доступ к административному разделу.
Разработанная база данных обеспечивает централизованное хранение информации, защиту конфиденциальных данных и возможность масштабирования системы за счёт добавления новых сущностей и модулей.

# Информационная система "Автовокзал"

> Название - АВ-Вокзал

## Сайт - ./frontend/

### Стек: NextJS, Axios, PrimeReact, TailwindCSS

Общедоступный сайт информационной системы. Имеет главную страницу с основной информацией.
Позволяет пользователю перейти на соответствующие функциональные страницы.
Сайт предоставляет следующий функционал:

- Регистрация/Авторизация
- Бронь билета
- Оплата брони
- Выбор маршрутов
- Добавление избранных маршрутов в личный кабинет

Также есть функционал администратора:

- Удаление/Изменение/Добавление маршрутов
- Удаление/Изменение/Добавление аккаунтов администратора
- Удаление/Изменение/Добавление аккаунтов водителей и операторов

Функционал водителей:

- Просмотр маршрутов
- Чат с оператором

Функционал операторов:

- Просмотр задержек
- Просмотр маршрутов
- Корректировка времени

Некоторые страницы доступны только определённым ролям. Проверка проводится на стороне сервера.

## Мобильное приложение - ./mobile/

### Стек: .NET LTS, MAUI, CommunityToolkitMVVM

Мобильное приложение позволяет пользователям оформить билет, оплатить его
и сесть в автобус, показав электронный билет или QR-код в приложении.
Функционал похож на функционал сайта для пользователя.

## Бекэнд - ./backend/

### Стек: NestJS, PrismaORM

Бекэнд информационной системы - построен под фронтэнд и мобильное приложение

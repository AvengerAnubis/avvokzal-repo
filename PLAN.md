# План: Информационная система "Автовокзал"

> **Архитектурные принципы:** Проекты изначально планировались как микросервисы/микрофронтенды (KAFKA, Redis и т.д.). 
> Из-за сжатых сроков реализуются как модульные монолиты. При разработке избегать сильных связей между компонентами, 
> использовать API-first подход и чёткое разделение на модули — для упрощения будущей конвертации.
